# EGFR Exon 20 NSCLC: Treatment Telemetry Analysis

## Part 1 — Initial Treatment Response

This project explores longitudinal clinical laboratory data from a
treatment timeline for EGFR exon 20 insertion–mutated non-small-cell
lung cancer (NSCLC).

The analysis focuses specifically on the laboratory changes observed
during treatment involving:

- Carboplatin
- Pemetrexed
- Amivantamab
- Steroid pre-medication
- G-CSF support
- Platelet support

### What I am exploring

Rather than looking at laboratory values independently, this analysis
tracks how:

Treatment → Laboratory Change → Supportive Intervention → Subsequent Change

appeared across the treatment timeline.

The main laboratory parameters analyzed are:

- WBC
- Neutrophils
- Platelets
- Creatinine

A clinical timeline is also used to connect laboratory changes with
documented treatment events, interventions, and symptoms.

### Part 1 Focus

The first stage examines the initial treatment period and asks:

How did blood counts and renal-related laboratory measurements change
during platinum chemotherapy and amivantamab treatment?

### Next Stage

The later treatment timeline raises a separate question around changes
in renal function. This will be investigated as a subsequent stage
rather than mixing the two analyses.
